# *Html Tasks Orange*
This is the first HTML tasks (7/9/2026) in Orange Training (Basics)

## Overview
Seven standalone HTML5 pages covering core markup fundamentals: images and links, text elements, lists, tables, and forms. Each page is wired to the next/previous one with **Next** / **Back** buttons, so the exercises can be walked through in order starting from [TaskOne-1.html](TaskOne-1.html).

## Tasks

| # | File | Topic | What it covers |
|---|------|-------|-----------------|
| 1 | [TaskOne-1.html](TaskOne-1.html) | Images & links | `<img>` with `alt`/`title`, using an image as a clickable link, an external link opened in a new tab |
| 2 | [TaskOne-2.html](TaskOne-2.html) | Headings & paragraphs | `<h1>`, `<hr>`, `<p>` |
| 3 | [TaskOne-3.html](TaskOne-3.html) | Lists | Nested ordered lists (`<ol type="I/a/1">`) and unordered lists (`<ul type="circle/square/disc">`) |
| 4 | [TaskOne-4.html](TaskOne-4.html) | Tables | A weekly class timetable built with `<table>`, `rowspan`, and `colspan` |
| 5 | [TaskOne-5.html](TaskOne-5.html) | Images in tables | Combining `<img>` and `<a>` inside table cells (a "favorite pets" table) |
| 6 | [TaskOne-6.html](TaskOne-6.html) | Forms – login | `<form>`, `<fieldset>`, `<legend>`, text and password inputs |
| 7 | [TaskOne-7.html](TaskOne-7.html) | Forms – registration | Text, email, radio, and `<select>` inputs inside a fieldset |

## How to view
Open [TaskOne-1.html](TaskOne-1.html) in a browser and use the **Next** / **Back** buttons to move through the exercises, or open any file directly.
