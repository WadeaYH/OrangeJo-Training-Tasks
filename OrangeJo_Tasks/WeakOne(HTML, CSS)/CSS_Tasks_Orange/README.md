# CSS_Tasks_Orange
This is the first CSS tasks (8/9/2026) in Orange Training (Basics)

## Overview
Five exercises that build on the HTML basics from [Html_Tasks_Orange](../Html_Tasks_Orange) and introduce CSS: external stylesheets, text/font styling, styling code snippets, box/border styling, and simulating a styled table with `box-shadow` and `border-radius`. Pages are connected via **Next** / **Back** buttons starting from [TaskTwo-1.html](HTML/TaskTwo-1.html).

## Structure
- `HTML/` — one HTML page per exercise (`TaskTwo-1.html` … `TaskTwo-5.html`)
- `CSS/` — the matching external stylesheet for each page (`TaskTwo-1.css` … `TaskTwo-5.css`)

## Tasks

| # | HTML | CSS | What it covers |
|---|------|-----|-----------------|
| 1 | [TaskTwo-1.html](HTML/TaskTwo-1.html) | [TaskTwo-1.css](CSS/TaskTwo-1.css) | Page-level and inline CSS styling: external stylesheet, class selectors, `color`, `background-image` |
| 2 | [TaskTwo-2.html](HTML/TaskTwo-2.html) | [TaskTwo-2.css](CSS/TaskTwo-2.css) | Styling text: `font-family`, `font-size`, `text-align` across headings and paragraphs |
| 3 | [TaskTwo-3.html](HTML/TaskTwo-3.html) | [TaskTwo-3.css](CSS/TaskTwo-3.css) | Styling a code snippet with `<pre>`/`<code>` and colored `property`/`value` spans |
| 4 | [TaskTwo-4.html](HTML/TaskTwo-4.html) | [TaskTwo-4.css](CSS/TaskTwo-4.css) | Styling article-style boxes: solid/dashed borders, descendant selectors, highlighted inline text |
| 5 | [TaskTwo-5.html](HTML/TaskTwo-5.html) | [TaskTwo-5.css](CSS/TaskTwo-5.css) | Table-like styling using `border`, `border-radius`, and `box-shadow` on highlighted cells |

## How to view
Open [HTML/TaskTwo-1.html](HTML/TaskTwo-1.html) in a browser and use the **Next** / **Back** buttons to move through the exercises.
